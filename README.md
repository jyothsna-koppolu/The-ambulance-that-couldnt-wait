# LifeLine AI

Intelligent emergency response, route optimization, and hospital decision support.

**Tagline:** Don't find the shortest path. Find the smartest path to treatment.

LifeLine AI is a **hackathon prototype**. It is decision support only. It does not replace medical professionals, emergency dispatchers, or authorized emergency infrastructure. Dashboard figures are **DEMO / SIMULATED DATA**.

## Phase 1 status

Frontend command-center shell is implemented:

- React + Vite + Tailwind CSS
- Application layout, sidebar, top navigation
- Dashboard KPIs, simulated map, alerts, timeline, comparison
- Placeholder pages for remaining modules

Backend, ML, real maps, and live APIs are **not** in this phase.

## Run

```bash
cd frontend
npm install
npm run dev
```

Build check:

```bash
cd frontend
npm run build
```

## Privacy

Anonymous patient IDs only. Do not collect names, phone numbers, or national IDs.
